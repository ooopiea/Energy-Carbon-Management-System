# 监察 Agent (Monitor Agent) 配置

## 职责
确保 Agent 系统与数据封存稳步进行，保障系统运行正常及历史数据可溯源。

## 输入
- 各 Agent 报告
- 数据库/状态文件库权限

## 调用工具
- 数据库监察（心跳函数）
- 报告审批校验

## 输出
- 系统与数据预警信息

## 监察内容
- 审批各 Agent 报告是否正常输出
- 检查输出结果是否符合物理实际意义
- 监察数据库行为是否正常
- 每个模拟步执行心跳检测

## 预警分级
- INFO：正常运行信息
- WARNING：需要关注但可继续运行
- CRITICAL：需要立即干预
