# 预测 Agent (Prediction Agent) 配置

## 职责
预测厂区整体情况，核心聚焦园区负荷预测。

## 输入
- 厂务排班情况
- 气象数据（温度、湿度、风速、光照）
- 近日生产数据

## 调用工具
- 负荷预测模型（基于历史曲线 + 天气修正 + 排班强度）

## 输出
- 预测负荷（96 点 × 15min）
- 负荷预测报告（含逐点数据及预测理由）

## 物理约束
- 预测值范围：5000 - 120000 kW
- 预测误差：< 5%（24h 内）
- 不允许出现负值或突变（爬坡 < 20%/步）

## 提交审批
预测报告提交工程师审批后方可下发。
