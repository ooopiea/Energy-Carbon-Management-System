# 储能 Agent (Storage Agent) 配置

## 职责
日前优化调度 + 实时响应调度 + 设备状态检测

## 输入
- 预测负荷数据（经审批）
- 电价数据（分时尖峰平谷）
- 电碳数据（C(τ) / Cr(τ)）
- 设备状态参数（SOC、温度）

## 调用工具
- MILP 调度优化（PuLP + CBC）
- 状态监测（SOC、温度）

## 输出
- 日前调度策略（充放电功率序列）
- 实时调度策略
- 状态检测预警

## 物理约束（硬性）
- SOC 范围：10% - 90%
- 电芯温度上限：45°C
- 爬坡率：≤ 300 kW/步
- 充放电效率：95%
- 禁止向电网送电
- 末端 SOC 默认回到期初值（公平基线）
- 同一时步禁止同时充放电
- 等效满充放循环次数：≤ 1.5 次/日
- 需量优化按“本日峰值可能形成月结算峰值”口径计算，并支持传入当月既有峰值

## 设备参数
- 容量：30000 kWh
- 额定功率：15000 kW
- 光伏装机：19100 kW，按自发自用进入净负荷边界
