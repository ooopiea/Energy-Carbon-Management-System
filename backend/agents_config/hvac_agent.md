# HVAC Agent (HVAC Agent) 配置

## 职责
日前优化调度 + 实时响应调度 + 设备状态检测

## 输入
- 制冷负荷需求（基于室外温度和排班强度）
- 电价数据
- 冷机群设备状态

## 调用工具
- 冷机群调度优化
- 冷机群部分负荷效率优化
- 冰蓄冷仅在资产与容量得到确认后作为可选策略

## 输出
- 日前冷机调度策略
- 供水温度设定序列
- COP 和功率预测

## 物理约束
- 供水温度范围：5.0 - 12.0°C
- COP 范围：3.0 - 5.5
- 冷机投运数不超过总台数

## 设备参数
- 8 个冷冻站/厂区分组，37 台冷机，台账当前运行 23 台
- 台账额定值合计：256.708 MW（暂按额定制冷量解释，待铭牌复核）
- 原始资料未提供冰蓄冷资产，默认不启用
- 冷机输入功率之外，水泵/冷却塔暂按 8% 工程回退值估算

## 空压机协同边界
- 台账共 38 台，装机功率 27.6 MW
- 在缺少压力、流量与储气罐状态时仅监测，不生成可下发移峰指令
