# 电费计算方式

> 数据来源：蓝思科技黄花园区厂务实际结算账单（2026年1-6月）
> 代码入口：`src/energy_agent_v2/algorithms/tariff.py` -> `TariffCalculator.calculate()`
> 文档日期：2026-07-27

## 电费组成

电费总计 = 电度电费 + 需量电费 + 政府基金及附加 + 力调电费 + 绿电环境价值

| 分量 | 口径 | 是否受储能调度影响 | 计算方式 |
|------|------|-------------------|----------|
| 电度电费 | 日度（96点逐点累加） | 是 | Sigma grid(t) x price(t) x dt |
| 需量电费 | 月度 | 间接（峰值降低可降需量） | max(实际, 申报) x 需量单价 |
| 政府基金及附加 | 月度 | 否（随电量走） | 总电量 x 0.04625 |
| 力调电费 | 月度 | 否 | (电度+需量) x -0.75% |
| 绿电环境价值 | 月度 | 否 | 绿电电量 x 0.00001 |

## 各分量详解

### 1. 电度电费（分时）

核心计算，按 15 分钟粒度逐点累加：

```
电度电费 = Sigma_{t=0}^{95} grid(t) * price(t) * dt     dt = 0.25h
```

grid(t) 是该时段从电网取用的平均功率（kW），price(t) 由该时段所属档位决定。
所有电量（含绿电部分）统一按分时电价计费，绿电不拆分。

### 2. 需量电费（基本电费）

```
需量电费 = max(实际最大需量kW, 申报需量kW) * 需量单价
```

- 需量单价：30.6 元/kW/月（黄花实际）
- 申报需量：110,000 kW（110 MW）
- 实际超过申报时按实际计，否则按申报计
- 这是月度固定费用，储能削峰可降低实际最大需量从而间接降低此项

### 3. 政府基金及附加

```
政府基金 = 总电量(kWh) * 0.04625 元/kWh
```

固定费率，随用电量走。

### 4. 力调电费

```
力调 = (电度电费 + 需量电费) * reactive_adjust_ratio
```

- 默认 -0.75%（奖励，功率因数达标打折）
- 负值表示减少电费

### 5. 绿电环境价值

```
绿电环境价值 = (总电量 * 绿电占比) * 环境价值单价
```

- 环境价值单价：0.00001 元/kWh（黄花实际）
- 绿电占总用电量比例：月度不同，5月约 10.1%
- 这是绿证/绿色环境属性的附加费用，极小额
- 绿电的电度电费已含在分时电度中，不重复计费

## 口径注意事项

1. **日月口径分离**：电度电费是日度值，需量/力调是月度值。
   展示单日电费时，需明确标注哪些是日度、哪些是月度摊分。

2. **绿电不拆分**：所有电量（含绿电）统一走分时电度。
   绿电环境价值是额外附加项，不参与分时电度，避免重复计费。

3. **需量优化**：储能削峰可降低实际最大需量。
   当实际峰值 < 申报需量时，需量电费不降（按申报计）。
   只有实际峰值超过申报时，降峰才有需量收益。
