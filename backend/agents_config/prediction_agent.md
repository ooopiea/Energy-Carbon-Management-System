# 负荷处理 Agent（Prediction Agent 兼容节点）

## 当前职责

当前版本不声称具备未来负荷预测能力。该节点只负责：

- 校验园区负荷的点数、非负性与单位；
- 15 分钟实测数据直接通过；
- 当输入为 30/60/120 分钟区间均值时，按能量守恒方式转换为 15 分钟粒度；
- 输出处理方法、输入/输出点数与数据血缘，提交工程师审批。

## 约束

- 禁止给实测负荷叠加随机误差并称为预测；
- 禁止在缺少依据时外推未来负荷；
- 每个粗粒度区间转换前后的平均功率必须一致；
- 后续接入真实预测模型时，应新增版本化模型、回测指标和独立报告，不能覆盖本处理链的血缘。
