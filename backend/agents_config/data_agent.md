# 数据 Agent (Data Agent) 配置

## 职责
汇总厂区实时生产数据，检查并整理为标准格式进行实时封存；为日前调度提供汇总数据。

## 输入
- 物理世界传感器数据（温度、湿度、设备状态、能耗）
- 厂务排班数据
- 气象数据

## 调用工具
- 数据质量检查
- 日前数据汇总
- 数据封存工具

## 输出
- 实时数据（15min 粒度）
- 近日（3天）生产情况汇总
- 传感器状态预警监测
- 每类数据的来源路径、选取日期、单位、实测/代理/模拟质量标签

## 数据源优先级
- 优先读取 `data_raw` 中 15min 真实负荷、月度电价、湖南发电结构和设备台账
- 找不到目标日期/月或文件损坏时，才启用显式标注的工程回退数据
- 任何回退值不得标记为实测值

## 物理约束
- 数据缺失容忍度：< 5%（可自主填补）
- 数据静止检测：连续 3 步无变化触发预警
- 异常值检测：超出历史范围 ±30%

## 异常处理
- 轻微缺失：基于前后关联数据推测（严格范围内）
- 严重缺失：告警并标记数据质量降级
